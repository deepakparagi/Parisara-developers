## 📌 About

Parisara Developers is a digital platform designed to highlight eco-friendly and sustainable real estate projects. Moving away from traditional, static property listings, this application utilizes modern web technologies to provide an interactive, smooth, and highly visual experience for potential investors and home buyers.

Built on top of a lightning-fast Vite build toolchain, the platform leverages Framer Motion for sophisticated UI transitions and Tailwind CSS for a strictly responsive, mobile-first design architecture.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| 🌿 **Eco-Centric Design** | UI/UX specifically tailored to highlight sustainable and green development |
| ⚡ **Lightning Fast** | Instant hot-module replacement (HMR) and optimized production builds via Vite |
| 🎬 **Fluid Interactions** | Complex layout animations and page transitions powered by Framer Motion |
| 📱 **Mobile-First Responsive** | Flawless rendering across all devices utilizing Tailwind CSS grid systems |
| 🧪 **Robust Testing** | Comprehensive unit and integration testing suite configured with Vitest and React Testing Library |
| 🔄 **Client-Side Routing** | Seamless, zero-refresh page navigation managed by React Router |

## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 18.x
- **npm** or **yarn**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/deepakparagi/Parisara-developers.git

# 2. Navigate into the project
cd Parisara-developers

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be available at `http://localhost:5173`

---

## 📋 Available Scripts

| Script | Command | Description |
|:---|:---|:---|
| **Dev Server** | `npm run dev` | Starts the Vite development server with HMR |
| **Build** | `npm run build` | Creates an optimized production build in `/dist` |
| **Preview** | `npm run preview` | Serves the production build locally for verification |
| **Lint** | `npm run lint` | Runs ESLint for code quality checks |
| **Test** | `npm run test` | Executes the Vitest testing suite |
| **Deploy** | `npm run deploy` | Automatically builds and deploys to GitHub Pages |

---

## 🌐 Deployment

This project is configured for automated deployment to **GitHub Pages**. 

To deploy a new version:
```bash
npm run deploy
```
This script will automatically run the production build process (`predeploy`) and push the `dist` directory to the `gh-pages` branch.
